# ET20 · Versión integrada para la muestra

1. Extraé el archivo ZIP completo.
2. Abrí `index.html` con Chrome o Edge.
3. Usá el menú para recorrer las 11 secciones, especialmente **Radio Remolacha**, **Espacios curriculares** y **Contacto**.
4. La navegación funciona sin conexión, pero el mapa, Instagram, la web de la radio y la recepción de consultas necesitan Internet.
5. El formulario permanece deshabilitado hasta configurar `js/contacto-config.js` según `integracion_planilla/README_CONFIGURACION.md`. No se envían datos hasta completar ese paso.
6. Las imágenes usadas están en `img/` y los scripts en `js/`.

Consulta `documentacion/INFORME_INTEGRACION_FINAL.md` para conocer cambios y pendientes.
